# brand-profile.md — template

Fill every section from the interview. Be specific and quotable — this file is reused by the downstream
agent to write on-brand copy and judge creatives, so generic filler ("we value quality") is worthless.
Prefer the user's own words. Where a fact is unknown, write `TBD` rather than inventing.
